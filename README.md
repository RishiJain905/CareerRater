# CareerRater

A blank website template ready for development.

## Project Structure

```
CareerRater/
├── index.html      # Main HTML file
├── style.css       # CSS styling
├── script.js       # JavaScript functionality
└── README.md       # This file
```

## Getting Started

1. Open `index.html` in your web browser to view the website
2. Edit the HTML content in `index.html`
3. Modify styles in `style.css`
4. Add JavaScript functionality in `script.js`

## Features Included

- Responsive design that works on desktop and mobile
- Clean, modern styling
- Smooth scrolling navigation
- Semantic HTML structure
- Ready-to-expand JavaScript foundation

## How to Develop

1. **HTML Content**: Edit `index.html` to add your content, forms, images, etc.
2. **Styling**: Modify `style.css` to change colors, fonts, layout, animations
3. **Functionality**: Add interactive features in `script.js`
4. **Assets**: Create folders like `images/`, `fonts/`, `icons/` as needed

## Browser Compatibility

This template works with all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
